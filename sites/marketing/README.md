# bigmarkt.co — Protocol marketing site

The public marketing site for BigMarkt at [bigmarkt.co](https://bigmarkt.co). Explains the protocol architecture and links out to the journal, club, and academy.

## Develop

```bash
cd sites/marketing
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

## Deploy

Auto-deploys to Vercel on push to `main`. The Vercel project is wired to `sites/marketing` as its root.
